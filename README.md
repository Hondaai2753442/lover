# مشروع لعبة الأزواج العربية — «من أنا؟» 💜
### Arabic Couples Game with Supabase Realtime & Offline-First Privacy

مشروع Flutter عربي متكامل (RTL) بتصميم عصري وأنيق (White & Purple Glassmorphism)، يجمع بين **لعبة تخمين الشخصيات بملامح عربية**، و**لعبة «قد إيش تعرفني؟» التفاعلية**، و**جلسات وبطاقات حوارية هادفة للأزواج**، ونظام **نقاط وإنجازات تحفيزي**، مع دعم اللعب المحلي (Offline-First) واللعب عن بُعد عبر غرف **Supabase Realtime**.

---

## 🌟 مميزات التطبيق وأوضاع اللعب

### 1. 🎭 خمن الشخصية (Guess Who)
- **24 شخصية عربية أصلية** بملامح وأزياء متنوعة ومحترمة (شماغ، غترة، حجاب، لحية، نظارات، بشرة فاتحة/حنطية، ثوب، ملابس يومية).
- اختيار الشخصية السرية لكل لاعب مع **شاشة تسليم الجهاز المحمية (Pass Device Screen)** لضمان الخصوصية ومنع كشف الشخصية.
- إمكانية استبعاد الشخصيات وإعادة إظهارها بنقرة واحدة، واستعراض بطاقة تفاصيل الشخصية بالضغط المطول.
- عداد للشخصيات المتبقية، وسجل تفاعلي لأسئلة وإجابات الجولة (`questionHistory`).
- تحقق تلقائي من التخمين النهائي وتحديد الفائز واحتساب النقاط وتبديل اللاعب البادئ.

### 2. 💜 لعبة «قد إيش تعرفني؟» (How Well Do You Know Me?)
- وضع لعب تفاعلي خاص مبني على أسئلة التفضيلات، العادات، الذكريات، والمشاعر.
- يكتب الشريك الأول إجابته سرًا مع إخفائها بالكامل، ثم يُسلم الجهاز للشريك الثاني لتخمين الإجابة.
- شاشة كشف ومقارنة تفاعلية مع احتساب النقاط (+15 نقطة للتطابق التام، و+5 نقاط للتقارب).
- إمكانية تخطي أي سؤال دون حرج أو خسارة، وإضافة أسئلة خاصة مباشرة.

### 3. ⏱️ جلسة الأزواج المنظمة (10 دقائق)
- جلسة يومية مدروسة من 4 خطوات متعاقبة:
  1. **المقدمة الخفيفة 🌱:** لكسر الروتين وفتح النفس.
  2. **سؤال التقارب 💜:** حوار هادئ وصادق يقرّب المسافات.
  3. **الامتنان والتقدير ✨:** تعبير عن الشكر وتحديات لطيفة.
  4. **التأمل الختامي 🌙:** لحظة هدوء واستشعار للدفء بين الشريكين.
- مؤشر تقدم مرئي، ومؤقت هادئ، وزر تخطي دائم.
- منع تكرار البطاقة داخل الجلسة الواحدة.

### 4. 💬 بطاقات الحوار والتحديات (100+ بطاقة)
- 100 بطاقة عربية أصلية مصنفة (التقارب، الامتنان، تحديات لطيفة، هذا أو ذاك، تأمل ومراجعة).
- مستويات متدرجة (خفيف، متوسط، عميق).
- محرك بحث وفلترة سريعة حسب الفئة والمستوى والكلمات المفتاحية.
- إمكانية حفظ أي بطاقة في المفضلة للرجوع إليها في أي وقت.

### 5. ✏️ إدارة الأسئلة الخاصة (Full CRUD)
- شاشة مستقلة لإدارة أسئلة الشريكين الخاصة.
- إضافة أسئلة مخصصة جديدة.
- تعديل الأسئلة المضافة.
- حذف الأسئلة بنقرة واحدة وتأكيد حماية.
- حفظ محلي فوري دائم عبر `PreferencesService`.

### 6. 🏆 نظام النقاط والمستويات والشارات (Gamification)
- نقاط تُكتسب عند كل لعبة وتخمين وجلسة مكتملة.
- رتب ومستويات متدرجة للعلاقة تعكس مدى التفاعل والتقارب.
- سلسلة الأيام المتتالية (Daily Streak Counter) لتشجيع الحوار اليومي.
- شارات وإنجازات حقيقية تُفتح تلقائياً (أول خطوة، شعلة الأسبوع، خبير التخمين، فاهم شريكي، حوار من القلب، مبتكر الأسئلة).

### 7. 🌐 اللعب عن بُعد عبر غرف Supabase السحابية
- إنشاء غرفة لعب سريعة برمز سداسي فريد (مثل `ABC123`).
- انضمام الشريك إلى الغرفة من هاتف آخر بالرمز.
- مزامنة حية للبطاقات والأدوار باستخدام قنوات **Supabase Realtime**.
- تسجيل الدخول وإنشاء الحسابات عبر **Supabase Auth** مع دعم كامل لوضع الضيف (Guest Mode).

### 8. ⚙️ إعدادات متقدمة وسهولة الوصول
- تبديل **الوضع الداكن (Dark Mode)** لأجواء مسائية مريحة.
- خيار **تقليل الحركة (Reduced Motion)** لمنع الإجهاد البصري.
- خيار التحكم في **حجم الخط (Font Scaling)** لقراءة مريحة لجميع الأعمار.
- تصفير البيانات وإعادة الضبط بوضوح عند الحاجة.
- شاشات سياسة الخصوصية وشروط الاستخدام داخل التطبيق.

## 🛡️ الخصوصية والأمان
- **Offline First:** التطبيق يعمل بنسبة 100% محلياً دون الحاجة لشبكة إنترنت.
- **حماية السرية التامة:** لا يتم كشف إجابة أو شخصية الشريك بفضل شاشات الحماية وحواجز الخصوصية.
- **Supabase RLS:** جميع الجداول في Supabase مؤمنة بسياسات أمان Row Level Security ولا يمكن لأي طرف ثالث قراءة بيانات الغرف الخاصة.
- **خلو الكود من الأسرار والمفاتيح الحساسة:** التطبيق يستخدم مفتاح Supabase المعلن فقط (`publishableKey`).
