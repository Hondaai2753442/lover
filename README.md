# مشروع لعبة الأزواج العربية — «من أنا؟» 💜
### Arabic Couples Game with Supabase Realtime & Offline-First Privacy

مشروع Flutter عربي متكامل (RTL) بتصميم عصري وأنيق (White & Purple Glassmorphism)، يجمع بين **لعبة تخمين الشخصيات بملامح عربية** و**جلسات وبطاقات حوارية هادفة للأزواج**، مع دعم اللعب المحلي (Offline) واللعب عن بعد عبر غرف **Supabase Realtime**.

---

## 🌟 مميزات التطبيق وأوضاع اللعب

### 1. 🎭 خمن الشخصية (Guess Who)
- 24 شخصية عربية بملامح وأزياء متنوعة (شماغ، حجاب، لحية، نظارات، بشرة فاتحة/قمحية).
- اختيار الشخصية السرية لكل لاعب مع **شاشة تسليم الجهاز المحمية (Pass Device Screen)** لضمان الخصوصية ومنع التلصص.
- أسئلة نعم/لا متدرجة مع تصفية ديناميكية وتأكيد التخمين واحتفال بالفائز.
- زر تخطي الدور متاح دائمًا.

### 2. ⏱️ جلسة الأزواج المنظمة (10 دقائق)
- جلسة يومية مدروسة من 4 خطوات متعاقبة:
  1. **المقدمة الخفيفة 🌱:** لكسر الروتين وفتح النفس.
  2. **سؤال التقارب 💜:** حوار هادئ وصادق يقرّب المسافات.
  3. **الامتنان والتقدير ✨:** تعبير عن الشكر وتحديات لطيفة.
  4. **التأمل الختامي 🌙:** لحظة هدوء واستشعار للدفء بين الشريكين.
- مؤشر تقدم مرئي وزر تخطي دائم.
- تسجيل سلسلة الأيام (Streak) يوميًا.

### 3. 💬 بطاقات الحوار والتحديات (100+ بطاقة)
- 100 بطاقة عربية أصلية مقسمة حسب الفئات (التقارب، الامتنان، تحديات لطيفة، التخمين، اختاروا سوا، تأمل ومراجعة).
- مستويات متدرجة (خفيف، متوسط، عميق).
- إمكانية حفظ البطاقات بالمفضلة وتخطي أي سؤال بسهولة.

### 4. ☀️ ألعاب إضافية ممتعة
- **سؤال اليوم:** يتغير تلقائيًا كل يوم بنظام تاريخي ذكي.
- **هذا أو ذاك:** خيارات سريعة تكشف التفضيلات المشتركة.
- **خمن إجابتي:** يكتب اللاعب الأول إجابته سرًا، ثم يخمنها اللاعب الثاني قبل كشف النتيجة ومقارنتها عبر شاشة تسليم الجهاز.
- **أسئلتنا الخاصة:** إمكانية إضافة وحفظ بطاقات وأسئلة مخصصة محليًا.
- **المفضلة:** تصفح البطاقات المحفوظة وحذفها بسهولة.

### 5. 🌐 اللعب عن بُعد عبر غرف Supabase السحابية
- إنشاء غرفة لعب سريعة برمز سداسي (مثل `ABC123`).
- انضمام الشريك إلى الغرفة من هاتف آخر.
- مزامنة حية للبطاقات والأدوار باستخدام قنوات **Supabase Realtime**.
- تسجيل الدخول وإنشاء الحسابات عبر **Supabase Auth**.

### 6. ⚙️ إعدادات متقدمة والخصوصية
- تبديل **الوضع الداكن (Dark Mode)** لأجواء مسائية مريحة.
- خيار **تقليل الحركة (Reduced Motion)** لذوي الحساسية البصرية.
- خيار التحكم في **حجم الخط (Font Scaling)**.
- خيار التحكم في الصوت والاهتزاز اللمسي.
- عداد سلسلة الأيام (Streak Counter).
- شاشة سياسة الخصوصية وشروط الاستخدام التابعة لمعايير المتاجر.

## 📂 هيكلة المشروع (Architecture)

```text
lib/
├── config/
│   └── supabase_config.dart          # إعدادات رابط ومفتاح Supabase
├── models/
│   ├── character.dart                # نموذج الشخصية وسماتها
│   ├── couples_card.dart             # نموذج البطاقة الحوارية
│   └── game_session.dart             # نموذج الجلسة المنظمة (4 خطوات)
├── screens/
│   ├── auth_screen.dart              # تسجيل الدخول وإنشاء حساب Supabase
│   ├── character_screens.dart        # شاشات خمن الشخصية والاختيار واللعبة
│   ├── couples_cards_screen.dart     # شاشة البطاقات والتحديات مع الفلترة
│   ├── extra_games_screen.dart       # سؤال اليوم، هذا أو ذاك، خمن إجابتي
│   ├── home_screen.dart              # الشاشة الرئيسية التفاعلية
│   ├── online_room_screen.dart       # شاشة غرف اللعب عن بعد (Realtime)
│   ├── pass_device_screen.dart       # شاشة تسليم الجهاز المحمية (P0 Privacy)
│   ├── privacy_screen.dart           # شاشة سياسة الخصوصية والشروط
│   ├── settings_screen.dart          # شاشة الإعدادات والوضع الداكن
│   └── structured_session_screen.dart # شاشة جلسة الـ10 دقائق
├── services/
│   ├── game_data_service.dart        # تحميل بيانات الـ JSON
│   ├── preferences_service.dart      # التخزين المحلي الآمن والسلسلة
│   └── supabase_service.dart         # خدمات المصادقة والغرف والمزامنة
├── theme/
│   └── app_theme.dart                # الثيم الفاتح والداكن والألوان والظلال
└── main.dart                         # نقطة البداية وإعداد الخط والاتجاه RTL

supabase/
├── schema.sql                        # مخطط قاعدة البيانات الكامل وسياسات RLS
└── schema_base.sql                   # المخطط الأولي

docs/
├── privacy_policy.md                 # سياسة الخصوصية الرسمية
├── terms_of_service.md               # شروط الاستخدام
├── STORE_LISTING.md                  # بيانات ونصوص متجر التطبيقات
└── RESEARCH_AND_ROADMAP.md           # خطة المنتج ومقارنة السوق
```

## 🛡️ الخصوصية والأمان
- **Offline First:** التطبيق يعمل بنسبة 100% بدون إنترنت.
- **حماية السر:** لا يتم كشف إجابة أو شخصية الشريك بفضل شاشة تسليم الجهاز المنفصلة.
- **Supabase RLS:** جميع الجداول في Supabase مؤمنة بسياسات أمان Row Level Security ولا يمكن لأي طرف ثالث قراءة بيانات الغرف الخاصة.
