# مشروع لعبة الأزواج العربية — نسخة موسّعة

مشروع Flutter عربي من اليمين لليسار، بواجهة أبيض/بنفسجي، يجمع لعبة تخمين الشخصية وبطاقات الحوار وألعابًا قصيرة إضافية. المشروع يضم ملفات المصدر والأصول الأساسية، لكنه **ليس تطبيق APK جاهزًا للنشر** ولا يتصل حتى الآن بخادم لعب عن بُعد.

## المزايا الموجودة في هذه النسخة

### 1) من أنا؟ — تخمين الشخصيات
- 24 شخصية تجريبية بأسماء وصفات عربية متنوعة.
- اختيار شخصية سرية لكل لاعب على الجهاز نفسه.
- أسئلة نعم/لا عن الجنس، العمر التقريبي، النظارات، اللحية، غطاء الرأس، الحجاب، الثوب، لون البشرة والشعر.
- استبعاد المرشحين غير المطابقين، تخمين شخصية، تحديد الفائز، وإعادة الجولة.

### 2) بطاقات الحوار والتحديات
- 100 بطاقة عربية أصلية في `assets/couples_cards.json`.
- أنواع متعددة: أسئلة، تقدير وامتنان، تحديات لطيفة، تخمين إجابة الشريك، اختيارات بين أمرين، وتأمل.
- مستويات خفيف ومتوسط وعميق.
- شاشة استعراض تدعم التصفية حسب الفئة والمستوى، تخطي البطاقة، وحفظ المفضلة محليًا.

### 3) ألعاب إضافية
- **سؤال اليوم:** سؤال يتغير حسب التاريخ المحلي للجهاز.
- **هذا أو ذاك:** اختيارات سريعة للعب والنقاش.
- **خمن إجابتي:** يكتب لاعب إجابته، ثم يكتب الطرف الآخر تخمينه قبل الكشف.
- **بطاقات خاصة:** إضافة أسئلة من المستخدم وحفظها محليًا.
- **المفضلة:** حفظ البطاقات التي يريد الزوجان الرجوع إليها.

### 4) الحفظ
- يستخدم `shared_preferences` لحفظ المفضلة والأسئلة الخاصة على الجهاز.
- لا يوجد حساب مستخدم مطلوب للنسخة المحلية.
- لا توجد مزامنة تلقائية بين هاتفين في هذه النسخة.

## التشغيل

المتطلبات: Flutter SDK حديث (Dart 3.3 أو أحدث)، وAndroid Studio لبناء Android. لبناء iOS تحتاج macOS وXcode.

```bash
flutter pub get
./setup_platforms.sh
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

يجب اختبار البناء على جهاز فعلي، لأن هذه الحزمة لم يتم بناؤها أو توقيعها في بيئة إنشاء الملفات هذه.

## بنية الملفات

```text
lib/main.dart                 الشاشة الرئيسية ولعبة تخمين الشخصية وبطاقات البداية
lib/extra_games.dart          سؤال اليوم، هذا أو ذاك، خمن إجابتي، المفضلة والأسئلة الخاصة
assets/characters.json        بيانات 24 شخصية وصفاتها
assets/couples_cards.json     100 بطاقة عربية
docs/arabic_character_ui_reference.png  مرجع بصري، وليس 24 صورة شخصية منفصلة
docs/RESEARCH_AND_ROADMAP.md  نتائج مراجعة المنافسين وخطة التطوير
supabase/schema_base.sql      مخطط أولي فقط، ليس قاعدة بيانات منشورة
```

## ما لم يُنفّذ بعد
- رسوم أصلية منفصلة للشخصيات الـ24؛ الموجود حاليًا رموز تعبيرية ومرجع تصميم.
- اللعب الفعلي عن بُعد بين جهازين، مزامنة الجولات، ودعوات الغرف.
- تسجيل الدخول والربط بين حسابي الزوجين.
- الإشعارات اليومية، السجل السحابي، النسخ الاحتياطي، والاشتراك/المشتريات.
- اختبارات آلية شاملة، اختبار وصول/خصوصية، مراجعة محتوى، وسياسة خصوصية وشروط الاستخدام.

## قبل النشر
1. استبدال رموز الشخصيات برسومات أصلية متسقة ومراجعة السمات حتى لا تكون مضللة أو نمطية.
2. مراجعة النصوص باللهجة المستهدفة واختبارها مع مستخدمين حقيقيين.
3. إعداد مشروع Supabase، وسياسات RLS ضيقة، واختبار أن الإجابات والشخصيات السرية لا تصل إلى الطرف الآخر قبل الكشف.
4. لا تضع مفتاح `service_role` في تطبيق الهاتف؛ احتفظ بالأسرار على الخادم فقط.
5. إعداد سياسة خصوصية وحذف الحساب والبيانات إذا أضيفت الحسابات.
6. اختبار RTL، تكبير النص، قارئ الشاشة، حالات انقطاع الشبكة، وأحجام الأجهزة المختلفة.
